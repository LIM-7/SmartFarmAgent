# BerryHarvestRobot 小浆果柔性采摘机器人（研究方向框架）

| 项目 | 内容 |
| --- | --- |
| 状态 | 框架初建（2026-08-29） |
| 定位 | 面向沙棘、枸杞等带刺小浆果的柔性无损采摘机器人 |
| 承接 | SmartFarmAgent（复用「感知—决策—执行」闭环架构） |

## 1. 方向定位

以视觉识别 + 柔性末端 + 智能决策，实现沙棘、枸杞等小浆果的低损伤、高效率机械化采摘，解决人工采摘成本高、招工难、果实损伤大的产业痛点。

## 2. 痛点依据（关键数据）

- 沙棘：果实仅黄豆大小、浑身带刺、果肉娇嫩；人工采摘约 20 kg/天，成本约 7 元/kg，招工困难；传统剪枝刮果法伤树、隔年减产。
- 枸杞：果实小而密集、与枝叶夹杂生长；熟果-果柄结合力约 0.758 N，青果约 1.879 N，力控窗口窄，需区分熟青。
- 现有机械：振动式、梳刷式采摘损伤率高、易误摘青果、损伤枝叶；全球尚无成熟的单果柔性采摘产品。
- 前沿进展：软体抓手研究活跃（黑莓、覆盆子等），但整链路成功率仍偏低（约 52%），研究与工程化空间大。

## 3. 技术路线（四层）

| 层 | 要点 |
| --- | --- |
| 感知层 | 小目标检测（YOLO 系）、深度估计（双目/单目）、成熟度分级（熟/青） |
| 决策层 | 采摘点选择、带刺枝条避障、运动规划（强化学习/规则） |
| 执行层 | 柔性末端（软体气动/夹爪/吸附），力控窗口适配果柄结合力 |
| 平台层 | 复用 SmartFarmAgent：Node.js + Vue 3 + MySQL + WebSocket（设备管理、数据、远程监控） |

## 4. 与 SmartFarmAgent 的承接

| SmartFarmAgent 模块 | 复用到本方向 |
| --- | --- |
| 视觉服务（YOLOv8） | 果实检测、成熟度识别 |
| 智能体决策 | 采摘方案、避障路径、采收窗口判断 |
| MQTT 设备链路 | 采摘机器人状态上报与控制 |
| 数据闭环 | 损伤率、采摘效率、产量反馈 |
| 四情监测 | 果情、成熟度监测延伸 |

## 5. 里程碑（草稿）

- M0 框架与调研：文献、专利、竞品调研，痛点量化，方案对比
- M1 视觉识别：沙棘/枸杞数据集构建，检测 + 成熟度分级
- M2 柔性末端：抓取力标定，果柄分离试验（约 0.7～1.9 N 力控）
- M3 整机原型：机械臂/移动平台 + 视觉 + 柔性爪联调
- M4 田间试验：采摘率、损伤率、效率指标验证
